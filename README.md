# Data Cleaning and Exploratory Data Analysis (EDA)

## Overview

This project focuses on inspecting, cleaning, and exploring the Iris dataset using Python.

## Objectives

- Inspect dataset structure and data types.
- Identify missing values and duplicate records.
- Clean the data where necessary.
- Perform exploratory data analysis using four visualizations.
- Document key findings and data quality issues.

## Dataset

The Iris dataset is a public dataset containing flower measurements and encoded flower classes.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Data Cleaning

- No missing values were detected.
- One fully duplicated record was identified and removed from the working dataset.
- Data types were inspected.

## Exploratory Data Analysis

Four visualizations were created:

1. Histogram of petal length
2. Boxplot of petal length
3. Scatter plot of petal length versus petal width
4. Correlation heatmap

## Key Findings

- Petal length and petal width show a strong positive correlation.
- The scatter plot shows visible groupings among the encoded flower classes.
- No potential outliers were visibly flagged by the petal-length boxplot.

## Conclusion

This project demonstrates the importance of data quality checks and exploratory analysis before applying machine learning techniques.
